# login_portal
Secure Login Portal (Frontend Demo)

A clean and responsive Login & Registration Portal built using HTML, CSS, and JavaScript.
This project demonstrates a basic authentication flow with client-side validation, password hashing, and smooth UI transitions—ideal for learning and portfolio purposes.

# Project Overview

The Secure Login Portal allows users to:

1.Register with a username, email, and password
2.Securely store credentials using SHA-256 password hashing
3.Log in using either email or username
4.Switch seamlessly between Login and Register views
5.Experience a modern, minimal UI with smooth animations

# ⚠️ This is a frontend-only demo using localStorage and is not intended for production use.

# Technologies Used

HTML5 – Structure and layout

CSS3 – Styling, animations, and responsiveness

JavaScript (ES6) – Form logic, validation, hashing, and localStorage handling

Web Crypto API – Secure password hashing (SHA-256)
